# Changelog

## 1.2.0 (2026-09-30)

### Changed

- With `rotate`, a move straight up or down (`pBegin` and `pEnd` with the same `x`) points the object along its path; it pointed backwards.
- With `rotate`, a frame where the object hasn't moved keeps its angle; the rotation became `nan`.
- A move stops when its object is removed, without calling `onComplete`; it went on setting the removed object's position until the time was up, then called `onComplete`.
- `move()` and `calculate()` raise an error at the caller's line for missing or wrong `params`, such as a missing `time` or a negative `height`, or points at the same height with a `height` of 0; they failed inside the module or moved the object to `nan`.
- Loads with the current dmc-corona-boot (1.6.0), and the examples use the current layout: `dmc_corona/`, `dmc_corona_boot.lua`, `dmc_corona.cfg`, generated by the new `Snakefile`. They had 2014 copies, of `dmc_library_boot.lua` and of an unused dmc-kompatible.

### Added

- `Trajectory.VERSION`.
- Unit tests, and `tests/run_unit.sh` to run them with plain Lua 5.1.
- A README with a Quick Start, the API and how to build; screenshots of the examples.

### Removed

- The unused configuration block and its copy of `extend()`, which leaked the global `_extend`.
